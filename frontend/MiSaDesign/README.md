# MISA design prototype

Responsive, clickable product-design prototype for a Malaysian merchant AI video production platform. The public landing page opens into a complete multi-screen creator Studio.

## View locally

```bash
python3 -m http.server 4173
```

Open `http://127.0.0.1:4173/` for the public landing page.

Open `http://127.0.0.1:4173/#designmap` to see the complete screen inventory.

## Important status

This is a design prototype. Buttons, forms, billing, provider integrations, publishing and metrics use illustrative local interactions and sample data. They are not connected to production services.

## Files

- `index.html` — application shell and accessibility entry points
- `styles.css` — responsive design system and components
- `app.js` — 29 page designs, public navigation and prototype interactions
- `assets/` — bundled landing-page and example imagery
- `DESIGN_SPEC.md` — page inventory, design logic and production handoff notes
